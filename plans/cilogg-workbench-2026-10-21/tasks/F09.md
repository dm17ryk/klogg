# F09 — Grouping, buckets, rates, windows, distributions, pivots, and exactness

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F08, F05, F06. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Put numerical/statistical semantics below chart renderers and expose trustworthy denominators, bounds and error state. **Depends on:** F08; F05/F06 for event-time/aligned/cross-source operations; P05 reducer primitive reuse only after behavior comparison. **Current anchors:** P05 exact occurrence counts; P06 planned regex/chart buckets; no general group/window/pivot engine in baseline.

**Proposed files:** create `src/analysis/include/{aggregateplan,aggregatereducer,bucketpolicy,windowreducer,distributionreducer,pivottransform}.h` and matching implementations; `tests/unit/{aggregatereducer,bucketpolicy,windowreducer,pivottransform}_test.cpp`; `tests/ui/datasetaggregation_test.cpp`; fixtures `test_data/analysis/aggregates/`. Extend QueryStage/schema/descriptor metadata and shared analysis result metrics.

**Interfaces:** `DataResult<AggregatePlan> compileAggregate(const QuerySpec&,const DatasetSchema&,const AggregateLimits&); DataResult<DatasetDelta> AggregateReducer::consume(const QVector<EventDelta>&,const ReduceContext&); DataResult<AggregateOutput> finalize(const CompletionContext&); DataResult<BucketKey> bucketFor(const FieldValue&,const BucketSpec&);`. `AggregateOutput` contains schema, bounded output rows and aggregate/precision metadata; the dataset service publishes it as a retained `AggregateDataset` handle. Aggregate functions: count-events/count-occurrences/count-present/count-invalid, exact-input sum/min/max/mean (with explicit arithmetic precision), first/last with declared event/physical ordering, variance/stddev with named population/sample policy, exact distinct, exact bounded quantile/median, histogram/2D histogram, group-by, pivot, top-N+Other and cumulative Pareto. Integer/decimal sums use checked exact arithmetic; mean follows the F08 division context; variance/stddev use named finite Float64 arithmetic with numeric-rounding metadata, not a sampling approximation. Window operators: fixed/tumbling, sliding, session with explicit inactivity gap, cumulative, moving count/time, lag/lead/delta/counter-rate. Every state structure is budgeted, cancellation-aware and retractable or explicitly marked needs-rescan.

Fix semantics: numeric bins and fixed elapsed buckets are half-open `[start,end)`, explicit origin/width; no auto-changing width during a frozen query. Calendar buckets carry IANA zone/calendar and actual UTC interval (23/25-hour days allowed). Event count rate is count / actual bucket duration in seconds, never match delivery speed. Counter rate uses declared monotonic/reset/wrap policy and per-series clock epoch; gauges use delta/elapsed only when explicitly requested. Null/missing/invalid samples contribute to their counters but not numeric sums/means. An empty bucket defaults to Missing; `fill=zero` is a query option with `synthetic=true`, valid only when scope/coverage can establish no events. Dropped/unreadable/unknown-time input remains Unknown coverage, not observed zero. State duration requires declared hold/interpolate/unknown-gap/end behavior.

Exact quantile uses versioned nearest-rank definition `x[ceil(p*n)]`, with p=0→minimum, p=1→maximum, and explicit empty handling; cap at 10,000 stored numeric samples/query by default. Optional approximate quantile registers a versioned bounded sketch, requested epsilon/compression/seed and merge behavior; metadata labels algorithm and approximation. No approximate percentile receives an invented accuracy guarantee. Top-N uses full-scope final aggregate, deterministic ties, and exact Other remainder from all excluded known groups; true top-N cannot be claimed if group cap was reached. Percentages include numerator/denominator fields and denominator scope. Pivot has explicit missing cells, row/column/cell caps and deterministic stable column identity.
