# U16 — Split the main window into panes

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md),
the shared contracts in [04-workspace.md](../04-workspace.md), and the
[split-pane design](../../../docs/split-panes.md). Execute only this task or its recorded,
independently reviewable slice.

**Integrated hard dependencies:** G01, G02, G03. See decision
[D12](../../../docs/workbench/decisions.md): implementation waits for the user's approval of the design.

**Outcome:** One CILogg window shows two or more panes, side by side or stacked; each pane has its own
file tabs and, per tab, its own log view and filtered views, like several CILoggs running in parallel.

**User request (2026-11-13):** "can we make main window splittable, like we run 2 and more ciloggs in
parallel. so every splitted part will have log files tabs and filtered part".

**Coordination:** U16 is the first slice of the pane layout U03 plans; U03's workspace snapshot later
embeds the pane layout, and U08 tab groups live inside a pane. All of them address tabs by tab id.

**Files and ownership:** create `src/ui/include/logpane.h`, `src/ui/src/logpane.cpp`; modify
`src/ui/src/mainwindow.cpp` (the 152 direct uses of `mainTabWidget_` move behind pane accessors),
`src/ui/src/mainwindowproject.cpp`, `src/ui/src/mainwindowregexlab.cpp`,
`src/ui/src/mainwindowvaluecounts.cpp`, `src/ui/src/session.cpp`, `src/app/kloggapp.h`,
`src/app/cli.h`, `src/ui/src/commander.cpp`. Tests: `tests/ui/workbench_u16_test.cpp`.

**Slices:** U16a pane tree, split / close / merge / move through menus, active pane, session and
project restore; U16b Commander / CLI / MCP / Python pane operations; U16c drag and drop between panes.

**Implementation steps:**

- [ ] Get the user's approval of the [split-pane design](../../../docs/split-panes.md) and record the
  answers to its open questions.
- [ ] Write the named cases: `layout_round_trip`, `moved_tab_keeps_search_follow_capture`,
  `close_pane_keeps_tabs`, `old_session_loads_into_one_pane`, `focused_tab_is_active_pane`,
  `tab_index_counts_across_panes`, `pane_operations_parity`.
- [ ] Build with the existing Windows build script, run
  `cilogg_itests.exe "[workbench][U16]" -platform offscreen`, and confirm the new cases fail for the
  missing behaviour.
- [ ] Implement each slice in the owned files.
- [ ] Rebuild, pass the focused cases and the relevant complete suites, add U16 cases to
  `tests/mcp/workbench_parity.py`, review the diff, and record evidence and limitations in
  PROGRESS.json. Deliver each slice as a focused PR with green hosted CI.

**Acceptance:** Two panes show different files with independent searches and filtered views; tabs move
between panes without restarting anything; the layout survives a restart; every existing Commander
tab selector keeps its meaning.

**Rollback:** Merge all panes into one; saved layouts are ignored and all tabs open in one pane.
