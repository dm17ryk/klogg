# MD06 — Decode AT conversations and nested SRING payloads in Wireshark

**Read first:** [decoder contract and acceptance matrix](../10-message-decoders.md), [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the owning F/E/U/D contracts.

**Integrated hard dependencies:** G01, G02, G03, MD02, MD04, MD05. Existing owner tasks retain their original edges; additional live/Protocol Lab/release capabilities are gated where stated below.

**Existing owners:** E09, F04, D17. **State:** planned; proposed names/files below are not implemented APIs.

**Files:** Audit installed dissectors first, then integrate versioned plugins/wireshark/at_sring_bridge.lua and selectable AT/vendor packs. Test tests/plugins/test_message_decoder_at_sring.py using sanitized transcripts and fragmented payload fixtures.

**Interfaces:** AT line/stream events -> ConversationResult plus independent URCs and EmbeddedPayload child streams. Preserve raw codes, exact typed values/units, clock quality, correlation confidence and ambiguity.

**Implementation steps:**
- [ ] Write failing cases for execution/read/test/set forms, CSQ and CEREG response/URC layouts, quoted commas, empty/new parameters, compound commands, echo and observed ATE/ATV verbose/numeric modes.
- [ ] For the synthetic CSQ transcript assert one OK transaction, one registration URC, 40 ms logged duration, RSSI -67 dBm and BER unknown; RX-only input stays unpaired.
- [ ] Test SMS/PDU multiline states, prompts, Ctrl-Z/ESC and data-mode literals containing AT/OK; never infer modem CR/LF from physical log lines without a declared envelope convention.
- [ ] Declare the SRING dialect/parameter meanings, validate wrapper length and hex fidelity, call the registered EHCP dissector in the real Lua runtime and retain parent/child source maps.
- [ ] Test one child frame split across notifications, two child frames in one notification, interleaved connections, odd final hex, checksum failures, cycles and expansion limits; unknown connection identity remains ambiguous.
- [ ] Keep per-direction assembly separate while correlating the shared device/channel conversation; clock gaps/EOF produce incomplete observations and historical decoding never sends commands or triggers actions.
- [ ] Before symbol edits run impact analysis and refresh relevant indexes. Register tests in existing CMake targets, tag integration tests `[ui]` or `[logdata]` as appropriate, observe failing then passing cases, run required complete checks and record evidence/limitations in PROGRESS.json. Use current build scripts from build_root.

**Acceptance:** AT responses/URCs and nested child messages retain independent statuses, query scopes and lineage. Comparable log clocks support observed durations only, not fabricated wire latency.

**Rollback:** Disable/revert consumers and public operations before shared backend/contracts; preserve original capture data, existing JSON previews, settings and plugin-v1 compatibility.
