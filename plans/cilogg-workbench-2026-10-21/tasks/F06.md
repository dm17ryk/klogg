# F06 — Sparse time lookup, elapsed-time navigation, clock alignment, and explicit chronological merge

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F05, F07. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Seek and compare times accurately across missing/duplicate/out-of-order events and multiple clocks. **Depends on:** F05; F07 source-set integration for cross-source operations. **Current anchors:** physical `SourceLocation` navigation and background analysis; P10/P11 time lookup remains planned. Chronological merge is separate from P07 folder search and file concatenation.

**Proposed files:** create `src/analysis/include/{timestampindex,timelookup,clockalignment,chronologicalmerge}.h` and matching implementations; `src/ui/include/timenavigationwidget.h`, `src/ui/src/{timenavigationwidget,mainwindowtime}.cpp`; tests `tests/unit/{timestampindex,clockalignment}_test.cpp`, `tests/ui/timenavigation_test.cpp`; fixtures `test_data/analysis/time/multisource-*`.

**Interfaces:** `QString buildTimeIndex(SourceSetHandle,const TimeIndexSpec&,QString* error); DataResult<TimeLookupResult> lookupTime(const TimeIndexHandle&,const TimeLookupSpec&); DataResult<AlignmentSnapshot> fitAlignment(const QVector<ClockAnchor>&,const AlignmentPolicy&); QString mergeChronologically(const SourceSetHandle&,const MergeSpec&,QString* error);`. `TimeLookupSpec{target,mode=exact|before|after|nearest,range,includeUnknown=false,tiePolicy=all|firstPhysical}`; results contain all matching bounded physical/event ranges and missing/ambiguous counters. Sparse checkpoints every 4,096 completed events plus per-block min/max, monotonicity and duplicate metadata; query refines candidate blocks, never binary searches an unverified whole file. Completion and candidate/refinement caps are visible.

`ClockAnchor` pairs observed points in named clock/boot domains with uncertainty. Start with explicit constant offset and optional affine drift using exact/rational coefficients relative to an anchor (avoid subtracting giant floating Unix times); require at least two anchors for drift, validate residuals and expose uncertainty/fit interval/extrapolation. Preserve original time alongside aligned derived time. No correlation-based automatic alignment silently takes effect. Merge validates compatible domains or explicit alignment, orders by aligned instant then manifest source order then physical event start/occurrence, and declares policies for unknown timestamps (`separate|drop|error`), duplicate records (default keep), and late arrivals. Out-of-order sources require bounded sorting/spill explicitly selected and budgeted; a streaming heap is permitted only for verified ordered partitions. Live merge labels a provisional watermark and bounded lateness; late data revise affected pages/windows or trigger a reported rescan.

- [ ] `F06_lookup_returns_all_duplicate_and_unordered_hits`: times `[10,12,10,missing,11]` return both physical 10s for exact, before(11)=both 10s, after(11)=12; nearest ties return all under tie=all; missing is excluded with count=1. A descending block is scanned/refined, never binary searched as ascending.
- [ ] `F06_alignment_is_explicit_and_revisioned`: anchors `(device0,host100)` and `(device1000,host1100)` fit slope 1/offset100; an anchor at host1101 produces reported residual, not a silently overwritten timestamp. Cross-boot subtraction without anchor fails `incompatible_clock_domain`; updated anchors invalidate aligned indexes but leave raw time values intact.
- [ ] `F06_merge_keeps_provenance_and_partial_status`: two sources `[1,3]`/`[2,3]` produce deterministic 1,2,3,3 order with original refs; identical bodies are kept unless dedup explicitly chosen; unknown times follow declared policy; over-cap disorder yields `sort_limit`, never a falsely ordered prefix. Late append revises only its declared bounded merge window or requests a rescan.
- [ ] Add `build_time_index`, `seek_time`, `query_time_range`, `delta_time`, `set_clock_alignment`, `get_clock_alignment`, `merge_sources_by_time`. GUI time seek/around-event/delta/merged virtual view and CLI/MCP agree on refs and uncertainty. Preserve source-tab navigation and raw ordering. Run time/source/navigation/query suites, then commit.
