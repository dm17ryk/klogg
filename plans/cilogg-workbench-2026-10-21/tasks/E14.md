# E14 — Editable plugin table cells, check-dropdown, toolbar and icon keys

**Read first:** [docs/plugin-views.md](../../../docs/plugin-views.md), [tasks/E13.md](E13.md),
CP_Infra `projTools/CiloggCpfTool/docs/2026-11-13-cpf-editing-design.md` section 3.

**Integrated hard dependencies:** E13 (plugin views) is merged (f87b00bb).

**Outcome:** plugins can make table cells editable (text, number, choice, multichoice, boolean), receive
`edited` view events, use a `multichoice` field, and choose toolbar/menu presence and an icon for actions and
views. The host announces `view_edit`.

**Depends on:** E13.

**Files and ownership:** `src/ui/src/pluginview.cpp`, `src/ui/include/pluginview.h`,
`src/ui/include/checkcombobox.h`, `src/ui/src/checkcombobox.cpp`, `src/ui/src/pluginviewhost.cpp`,
`src/ui/src/pluginuicontroller.cpp`, `src/plugins/src/pluginmanifest.cpp`, `src/plugins/src/pluginprocess.cpp`,
`plugins/sdk/python/cilogg_plugin.py`, `plugins/examples/view-demo/`, `docs/plugin-views.md`, tests.

**Interfaces (proposed additions):** column `editable`; row `editors`, `tooltip`; tone `accent`; field kind
`multichoice`; event `edited` (`row_id`, `column_id`, `value`, `previous`); manifest `toolbar`, `menu`, `icon`;
host feature `view_edit`.

**Required behavior:** see decision D12 and docs/plugin-views.md sections 2.1-2.3 after this task.

**Implementation steps:**
- [ ] Manifest keys and validation
- [ ] Toolbar, menu and icon in the Plugins UI
- [ ] CheckComboBox and the multichoice field
- [ ] Editable cells, pending state, edited event, revert on stop
- [ ] Python SDK helpers, view-demo, docs

**Acceptance:** `cilogg_itests "[workbench][E14]"` and `cilogg_tests "[plugins]"` pass; E13 tests still pass;
CI green.

**Rollback:** revert the PR; plugins that use the new keys fall back to read-only tables (no `view_edit`).

**References:** decision D12 in [docs/workbench/decisions.md](../../../docs/workbench/decisions.md).
