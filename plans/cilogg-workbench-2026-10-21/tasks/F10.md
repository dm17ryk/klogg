# F10 — Dataset lineage, derived-value explanation, and bounded drilldown

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F07, F08, F09, F04. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Make every event row, aggregate, point, bucket, Other category, pivot cell and derived value explainable and navigable. **Depends on:** F07–F09; F04 for multiline. **Current anchors:** `AnalysisJobService::location`, P05 first-occurrence/open/apply actions, source accepts/revision checks. Extend these, do not turn chart coordinates or row indexes into source line numbers.

**Proposed files:** create `src/analysis/include/{datasetlineage,datasetdrilldown,derivedvalueexplanation}.h` and matching implementations; `src/ui/include/datasetinspectordock.h`, matching implementation and MainWindow integration; tests `tests/unit/datasetlineage_test.cpp`, `tests/ui/datasetdrilldown_test.cpp`; update dataset schema and command catalog.

**Interfaces:** implement `AnalysisDatasetService::drilldown` and extend F07's existing `resolve`/asynchronous `materialize` to aggregate lineage; `DataResult<LineageDefinition> DatasetLineage::definition(const LineageHandle&) const; DataResult<ValueExplanation> explainValue(const QString& jobId,const QString& rowId,const QString& fieldId) const;`. Reuse F07's `registerOriginResolver` registry: F16 registers deferred files and D01 registers managed recording segments independently of F10. `LineageDefinition` holds immutable source-set handle, normalized upstream query, grouping/bin/window predicate and transform membership selector. `ValueExplanation` includes formula/version/input field IDs, original/normalized values, unit conversion, lookup/alignment revisions, algorithm/exactness and errors. Retain at most16 bounded witness refs and at most16 KiB lineage metadata/row within existing row/result budgets; full contributors come from a child re-query, not memory accumulation.

Drilldown preserves the parent frozen manifest and adds its exact predicate, e.g. category set for Other or `[bucketStart,bucketEnd)`. A pivot totals row uses the correct union, not just its first child. Approximate/sketch/sample points declare that membership is range/predicate/candidate based and may require refinement; they never claim an exact single event. Dispatch resolution by the discriminated origin. Physical origins validate first and last real SourceLocations, provisional revision, format/assembly version and raw spans. Inline origins are inspectable but have no viewer navigation. Deferred file origins return `deferred_resolution_required` until F16's asynchronous materialization validates the strong frozen-prefix digest or immutable backing, rechecks actual byte-to-line mapping/encoding/assembly, opens/indexes through the normal owner-thread path and obtains fresh SourceLocations with a fresh open UUID. Original deferred provenance remains unchanged and is returned alongside the new binding; an old LogData UUID is never reused or relabeled. A changed former provisional tail fails even if its old frozen prefix is still present. Managed-byte origins delegate to the registered recording/segment/generation resolver and open byte/frame context; no line or text position is synthesized. Historical/expired backing returns an explicit reason, retaining inspectable lineage. A caller can explicitly re-run against current data as a new job with a documented provenance difference.

- [ ] `F10_derived_value_has_complete_explanation`: aligned rate derived from counter/times returns original input values/units/boot IDs/alignment revision/denominator and formula; lookup-derived labels show lookup revision; error cells expose conversion cause without logging bodies.
- [ ] `F10_lineage_is_bounded_revisioned_and_stale_safe`: million-event aggregate stores no million-reference vector; retained metadata stays within configured caps; a stale live revision handle returns `stale_dataset_revision`; released/expired parent returns `result_expired`; source rewrite/close disables navigation while retaining historical metadata.
- [ ] `F10_deferred_and_managed_origins_never_forge_text_locations`: fake deferred resolver first returns `deferred_resolution_required`; successful materialization returns a new physical UUID while preserving the original manifest/entry reference; digest mismatch returns `stale_source`; an old provisional tail after append returns `provisional_replaced`; unavailable managed resolver returns `resolver_unavailable`, and a valid managed resolver returns the exact byte/frame range without a line/UTF-16 field. Test with fake providers here; F16/D01 own real backing fixtures.
