# U15 — One source picker for every tool that takes a tab

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md),
the shared contracts in [04-workspace.md](../04-workspace.md) and the source-set contract in
[02-data.md](../02-data.md). Execute only this task or its recorded, independently reviewable slice.

**Integrated hard dependencies:** G01, G02, G03. See decision
[D12](../../../docs/workbench/decisions.md): the user authorized this task ahead of G02/G03 completion
on 2026-11-13.

**Outcome:** Value Counts, Regex Lab and every other tool that works on "a tab" lets the user choose
the source: a specific tab, a file, the focused tab, or all opened files.

**User request (2026-11-13):** "Value Counts and Regex lab should be able to choose tab/file/focused
or all opened files" and "actually each tool that uses tab, should be able to choose tab/file/focused
or all opened files".

**Inventory (2026-11-13, master `76542bb3`):**

| Tool | Source today |
|---|---|
| Regex Lab, Value Counts | Own, duplicated combo: "current tab at Run", the tabs of this window, a closed source, pasted text. Apply always targets the current tab. |
| Analysis CLI (`regex_evaluate`, `value_counts`, Regex Lab / Value Counts commands) | `--tab-id`, or `--window-index` with `--tab-index`, else the focused tab |
| Preview message, Send to Preview | The tab whose context menu was used, or `--tab-id` / `--line` |
| Plugin actions and plugin views | The current tab when the action runs |
| Script Runner | The active window's current COM tab; rerun/stop use the run's tab |
| Search, filters, follow, Quick Find, encoding, save, file operations | The current tab, or the Commander tab selector |
| Actions window, responses, COM controls | COM tabs only, picked by MRU or the Commander tab selector |

Analysis jobs take exactly one source (`AnalysisRequest`), at most 10 run at once and 26 are retained.
The plan's F07 adds a real source-set request; the selectors here are designed to map onto its
`SourceSelector` later.

**Slices:**

- **U15a** — a shared `SourceSelection` (`focused`, `tab:<id>`, `file:<path>`, `all`) and source
  picker widget, used by Regex Lab and Value Counts. Tabs of every window are listed. "All opened
  files" runs one job per source (bounded, with a visible limit); Regex Lab groups results by source
  and Value Counts merges counts with a per-source breakdown. Apply and Open go to the tab a result
  came from, in whichever window holds it. A file that is not open is opened in a tab first. The
  dock definitions (`set_regex_lab`, `set_value_counts`) accept
  `source: focused|all|tab:<id>|file:<path>` and keep `sourceTabId`; the low-level analysis
  commands keep their existing tab selectors.
- **U15b** — the same picker for plugin actions and views, Script Runner, Preview and a
  search-all-open-tabs operation. COM-only tools (actions, responses, COM controls) keep a COM-tab
  picker; global settings (highlighters, preview decoders) need none.

**Files and ownership (U15a):** create `src/ui/include/analysissource.h` and
`src/ui/src/analysissource.cpp` (selection, resolution and the shared picker); modify
`src/ui/src/regexlabdock.cpp`, `src/ui/src/valuecountdock.cpp`, `src/ui/src/mainwindowregexlab.cpp`,
`src/ui/src/mainwindowvaluecounts.cpp`, `src/app/kloggapp.h` (every window's tabs and routing to
the window that owns a tab). Tests: `tests/unit/analysissource_test.cpp`,
`tests/ui/regexlabdock_test.cpp`, `tests/ui/valuecountdock_test.cpp`.

**Rollback:** The picker falls back to "focused tab"; existing tab selectors keep working.
