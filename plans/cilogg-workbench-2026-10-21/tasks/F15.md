# F15 — Snapshot dataset export and optional OpenTelemetry record mapping

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F07, F08, F09, F10. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Export reusable typed data with source lineage and interoperable log roles while preserving exact values, revisions and partial status. **Depends on:** F07–F10; F12 for explicitly enriched/display exports; F13 only for compressed original-source access. **Current anchors:** P05 atomic `export_value_counts` CSV, `QSaveFile` use, current configuration exports; P13c dataset CSV remains planned. Reuse atomic destination/partial/source-file protection.

**Proposed files:** create `src/analysis/include/{datasetexport,otellogmapping}.h` and matching implementations; `tests/unit/{datasetexport,otellogmapping}_test.cpp`, `tests/ui/datasetexportjob_test.cpp`; `schemas/cilogg-dataset-export-v1.schema.json`; sample requests and `docs/dataset-export.md`. Modify existing command catalog/MainWindow actions and only the shared export primitives needed by P05.

**Interfaces:** `QString exportDataset(AnalysisDatasetService&,const DatasetExportSpec&,QString* error); DataResult<MappedLogRecord> mapToOtel(const EventRecord&,const OtelMappingProfile&,const MappingContext&); DataResult<EventRecord> mapFromOtel(const MappedLogRecord&,const ImportContext&);`. `DatasetExportSpec{jobId,datasetRevision,format=csv|tsv|jsonl|cilogg_bundle,columns,valueMode=raw|typed|display,destination,allowPartial=false,spreadsheetSafe=false,includeLineage=true}`. Export is a normal cancellable analysis job, freezes dataset/schema/query/source manifest, streams to an atomic sibling temporary, rejects source/backing/cache destinations and requires explicit `allowPartial` for partial data. Failure/cancel cannot replace an existing target. CSV fixes UTF-8/BOM option, delimiter/newline/quote policy and original column order; typed JSONL uses tagged values; bundle adds schema/query/profile/time/alignment/lookup manifest and raw-reference availability, not unlimited raw logs by default. Exact integers/decimals are text in CSV with schema/metadata guidance; spreadsheet-safe escaping is opt-in and recorded. Raw bytes versus decoded raw text versus display labels are separate explicit choices; exact byte export fails `raw_unavailable` when source provenance cannot be validated.

Optional OTel mapping is a data adapter, not a mandatory Collector/network/backend dependency. Map declared event time, observed receipt time, severity text/number, body, resource/scope, traceId/spanId/flags and attributes; retain unmapped originals and a mapping report. Offline file-analysis time is not fabricated ObservedTimestamp. Unknown local/uptime time stays a typed custom attribute or unmapped with reason unless explicit resolution/alignment makes a valid instant. Canonical UInt64 above signed range, Decimal and Missing need a documented lossless CILogg extension/tag/string policy because OTel AnyValue/transport does not represent every canonical tag directly; do not silently cast UInt64 to double or Null to empty string. Preserve existing trace IDs only after validating their format; do not generate correlation IDs that imply known tracing relationships. Import/export is local file based in this task; live OTLP transmission would be a separate explicit feature.

- [ ] `F15_exports_are_exact_atomic_and_snapshot_bound`: quotes/newlines/Unicode/empty/null/missing/UInt64 max/decimal values export with declared semantics; append during export does not extend the frozen dataset; injected write failure/cancel leaves existing destination unchanged and removes temp; same-source destination rejects; partial export requires allowPartial and includes reason.
- [ ] `F15_export_lineage_is_usable_without_false_navigation`: bundle/JSONL row IDs include source manifest and lineage metadata; restored historical data stays inspectable but does not claim an open current source. Raw-byte export after replacement/close fails raw_unavailable unless a validated bounded backing snapshot exists; decoded/display modes never claim byte identity.
- [ ] `F15_otel_mapping_preserves_roles_and_reports_limits`: event/observed times remain separate, unknown zone is not UTC, severity/body/trace/resource round-trip according to profile; UInt64 max and Decimal preserve exact canonical extension; unsupported/missing fields appear in mapping report. No local export initiates network transmission.
- [ ] Add `export_dataset`, `get_dataset_export`, `validate_otel_mapping`, `import_otel_logs`, `export_otel_logs`. GUI export options/state/partial acknowledgement and CLI/MCP produce the same bytes/metadata/errors from identical requests; run export/query/source/P05 regressions and parity, then commit.

**Acceptance:** a developer can reproduce a dataset from a manifest/query against still-valid sources, understand every exported number, and see precisely what an interoperability mapping changed. **Rollback:** remove individual export/mapping routes; retain native dataset viewing and existing Value Counts export; versioned files remain readable by their codec. **Primary references:** [R1](https://opentelemetry.io/docs/specs/otel/logs/data-model/), [R2](https://doc.qt.io/qt-6/qjsonvalue.html), [R5](https://www.rfc-editor.org/rfc/rfc4180), [B4](https://github.com/dm17ryk/klogg/blob/01cb637be7c96f2c9e3925247510c162380736b7/src/logdata/include/valuecountjob.h).
