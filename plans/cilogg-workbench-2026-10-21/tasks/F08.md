# F08 — Typed query AST, filters, formulas, projection, and bounded deterministic sorting

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F01, F07. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Make filtering/calculating/ordering reusable across fields, tables, charts and automation. **Depends on:** F01/F07; F05 for time arithmetic. **Current anchors:** legacy raw regex/search modes, P13 planned grammar/sorting, current literal filter application from P05. Do not silently replace legacy regex semantics.

**Proposed files:** create `src/analysis/include/{querycompiler,queryevaluator,expressionfunctions,datasetsort}.h` and matching implementations; `tests/unit/{querycompiler,queryevaluator,datasetsort}_test.cpp`; fixtures `test_data/analysis/query/`; modify query schema/catalog and query controls in `structuredlogview`/field explorer. New text grammar `cilogg-query-v1` compiles to the same AST used by a structured builder; callers can submit AST directly.

**Interfaces:** `DataResult<QuerySpec> compileQuery(QStringView,const DatasetSchema&,const QueryCompileOptions&); DataResult<QueryPlan> planQuery(const QuerySpec&,const DatasetSchema&,const QueryCapabilities&); DataResult<FieldValue> evaluateExpression(const Expression&,const EventRecord&,const EvaluationContext&); DataResult<TruthValue> evaluateFilter(const Predicate&,const EventRecord&,const EvaluationContext&);` where `enum class TruthValue{False,True,Unknown};`. Operator nodes: and/or/not, ==/!=/<…>, exists/is_missing/is_null/is_invalid/is_empty, typed in, contains/prefix/suffix, regex, arithmetic + - * /, explicit casts, coalesce, case/if, unit conversion, date/time components and string extraction. Query limits: 256 AST nodes, nesting 32, 64 expressions, bounded regex worker budget. No implicit text→number cast; mixed numeric operations use exact representable promotion or a reported precision/overflow error. Decimal add/subtract/multiply operate on bounded base-ten coefficients; division has explicit `precision=34,rounding=half_even` default context and reports rounding in numeric-precision metadata rather than claiming an exact decimal result. Division by zero produces Invalid + error count; unit mismatch rejects planning. Arrays require explicit any/all/explode; explode has row/state caps and a child occurrence ordinal.

Missing/Null comparisons yield Unknown; final filters accept True only, preserving Unknown counters. `is_*` predicates select those states deliberately. Three-valued boolean rules are documented and identical in GUI preview/AST execution. Numeric equality compares mathematical exact values where representable; grouping preserves the configured type/key policy. `order` defaults to explicit null/missing placement, ordinal UTF-16 text collation, exact numeric ordering and stable source-manifest/physical/occurrence ties; user-selected locale collation is versioned in the query. Sort uses at most its declared row/byte cap; it cannot label a sort complete unless it considered the entire chosen scope. A later spill implementation is separate and opt-in. `limit N` after order is top-N semantics; limiting input before order is a distinct explicit sample stage.

- [ ] `F08_filter_has_documented_three_value_semantics`: events `{x:missing},{x:null},{x:0},{x:"0"},{x:""}` produce exact expected IDs for exists/is_missing/is_null/is_empty/x==typed0 and not(x==0); precedence `a OR b AND c` differs from `(a OR b) AND c`; escaped field IDs/string literals round-trip.
- [ ] `F08_formulas_preserve_precision_and_units`: `9007199254740993+1` equals exact `9007199254740994`; UInt64 overflow is Invalid/overflow; decimal `0.1+0.2` equals decimal `0.3`; `12ms/3` yields 4ms; `1ms+1byte` is a plan error; zero divide is never zero. Regex formulas obey child-process deadline and cannot bypass per-record limits.
- [ ] `F08_sort_never_sorts_only_loaded_rows`: values `2,10,1` sort as 1,2,10; exact max UInt64 remains greater than adjacent values; equal values use stable source ties; a 10,001-row fixture with sort cap10,000 returns `sort_limit` and physical/partial state explicitly, even if GUI loaded only 200 rows. Append during sort leaves frozen input unchanged.
- [ ] Add `compile_query`, `validate_query`, `explain_query`, `query_dataset` typed grammar/state. GUI builder/text mode previews the compiled AST and uses the same job; CLI/MCP errors include stage/field/code. Apply-to-raw-search remains an explicit escaped-literal action only when representable. Run query/table/legacy regex/P05 regressions and parity, then commit.
