# F01 — Canonical exact values, event identity, source spans, and dataset wire contract

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Establish one definition of a log event and a typed result before parsers/charts introduce incompatible copies. **Depends on:** merged P03/P04/P05; preserve the existing P05 shared source files and published semantics. **Current anchors:** `sourcelocation.h`, `analysisjob.h`, `analysisjob.cpp`, `analysiscommands.h`, `analysisregex.h`, P05 `valuecountjob.h`; no generic event/typed dataset contract exists in the checked master tree.

**Proposed files:** create `src/logdata/include/{fieldvalue,eventrecord,datasetschema,queryspec}.h`, `src/logdata/src/{fieldvalue,eventrecord,datasetschema,queryspec}.cpp`, `schemas/cilogg-dataset-v1.schema.json`, `docs/analysis-datasets.md`; the early visualization task creates `src/logdata/{include/capturedatasetadapter.h,src/capturedatasetadapter.cpp}` against these contracts. Modify `src/logdata/CMakeLists.txt`, `tests/unit/CMakeLists.txt`, and only the required additive batch metadata in `analysisjob.h`/reader code. Create `tests/unit/datasetcontracts_test.cpp` and fixtures `test_data/analysis/typed-values.jsonl`.

**Interfaces:** fix the types above. Produce `DataResult<FieldValue> parseTypedValue(QStringView raw,const FieldSchema& schema); QVariantMap encodeFieldValue(const FieldValue&); DataResult<FieldValue> decodeFieldValue(const QVariantMap&); DataResult<EventRef> makeEventRef(const SourceSnapshot&,LineNumber first,LineNumber last,std::optional<RawByteRange>,const EventIdentityPolicy&); EventRef makeInlineEventRef(const InlineEventOrigin&,const EventIdentityPolicy&); DataResult<EventRef> makeDeferredEventRef(const DeferredFileOrigin&,const SourceManifestEntry&,const EventIdentityPolicy&); DataResult<EventRef> makeManagedByteEventRef(const ManagedByteOrigin&,const EventIdentityPolicy&); bool acceptsEvent(const SourceSnapshot&,const EventRef&); DataStatus validateEventOrigin(const EventRef&);`. `acceptsEvent` applies only to PhysicalEventOrigin and refuses to treat deferred/managed origins as open-source locations. `EventIdentityPolicy` contains format ID/revision, assembly revision and occurrence ordinal. Add optional `AnalysisLineProvenance` to `AnalysisLine`: source snapshot identity for real open sources or explicit deferred manifest identity, actual indexed/read byte start/end, terminator bytes, provisional flag; populate it from the reader/index, not re-encoded text. Existing `AnalysisLine::text` and raw capture CRLF behavior remain unchanged. Retain raw input through original source/managed backing references; keep only bounded provisional bytes for replacement.

- [ ] Add `F01_values_roundtrip_without_loss`: round-trip `18446744073709551615` as UInt64; `9007199254740993` as Int64; decimal `12345678901234567890.00100` as coefficient/scale and preserved raw lexeme; preserve separate Missing, Null, `""`, `false`, zero and Invalid. Wire round-trip is identical on Qt5 and Qt6; decoding an unknown tag returns `unsupported_value_type`.
- [ ] Add `F01_spans_use_source_bytes_and_utf16`: BOM/UTF-16 fixture with an astral character has raw byte offsets from the index and a two-code-unit UTF-16 span; byte boundaries never include the synthetic EOF+1 marker; overflow/out-of-line spans fail. A multiline event ending on an old provisional line fails `acceptsEvent` after append even when its first completed line remains acceptable.
- [ ] Implement/verify schema versioning, explicit shape/type/unit/clock roles, exact numeric serialization, and dataset revision cursors. `F01_closed_or_replaced_source_cannot_resolve` must return `stale_source`/`source_closed`; retained values remain inspectable with historical metadata. `F01_origins_are_discriminated_without_fabricated_locations` round-trips exactly one physical/inline/deferred-file/managed-byte origin; rejects zero/two origins, reversed/overflowing byte ranges and a physical first/last from different source generations; deferred entries need their manifest verification binding; managed origins preserve recording/segment/generation/bytes and have no line/UTF-16 anchor. This contract test uses an in-memory fake resolver and does not require F16/D01 implementations.
- [ ] Run `[data][F01]`, existing `[source]`, `[analysis]`, regex and P05 suites; add direct/CLI/MCP codec parity for `describe_dataset` and `get_analysis_results` typed envelopes. Internal contracts may land without a new menu, but no consumer may publish an unversioned shape. Commit after these checks.

**Acceptance:** raw view, typed inspector and all transports show the same exact values and physical range; table row 7 never becomes line 7 by assumption. **Rollback:** remove unused contract adapters first; retain original source-location and analysis APIs, and ignore unknown additive metadata in older clients. **Primary references:** [B1](https://github.com/dm17ryk/klogg/blob/bd74c338424845a2caac03d62fdff5187e7e8f0a/src/logdata/include/sourcelocation.h), [B2](https://github.com/dm17ryk/klogg/blob/bd74c338424845a2caac03d62fdff5187e7e8f0a/src/logdata/include/analysiscommands.h), [R1](https://opentelemetry.io/docs/specs/otel/logs/data-model/), [R2](https://doc.qt.io/qt-6/qjsonvalue.html); OTel is semantic input, not a replacement storage schema.
