# F13 — Disposable indexes/caches and shared bounded zstd/lz4 inputs

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F01, F05, F07, F11, F16. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Improve repeated large-log work without making caches authoritative or creating a second input path for compressed/folder logs. **Depends on:** F01/F05/F07/F11; F16 supplies the shared bounded stream reader for the compressed-input slice. Ordinary analysis does not depend on this task. Integrates P22/P23. **Current anchors:** `src/logdata/include/{compressedlinestorage,linepositionarray,filedigest,logdataworker}.h`, indexing boundaries; current `src/ui/{include,src}/decompressor.*` uses KArchive/KCompressionDevice with no zstd/lz4 switch cases. Existing in-memory search-result caches are distinct.

**Proposed files:** create `src/analysis/include/{datasetcache,fieldindex,timeindexcache,cachekey}.h` and matching implementations; `src/logdata/include/{indexcache,compressedsource}.h` and matching implementations; `tests/unit/{datasetcache,indexcache,compressedsource}_test.cpp`, `tests/ui/cacheinvalidations_test.cpp`; update decompressor adapter, appropriate current CMake/dependency/package manifests, source/file-origin metadata and cache UI. F16 owns ordinary-file `boundedstreamreader.*`; when that optional capability is enabled, F13 adds compression adapters through it rather than a second folder reader. F13 can still provide managed decompressed backing for normal open-file analysis before F16 lands. First inspect the vendored/packaged KArchive version and available formats; if it already supplies the required streaming format use it, otherwise isolate optional zstd/lz4 frame dependencies below the shared reader. Do not add Qt Charts or a database merely to obtain caching.

**Interfaces:** `CacheKey makeDatasetCacheKey(const SourceManifest&,const ParseSnapshot&,const QuerySpec&,const LookupSnapshot&); DataResult<CacheHandle> DatasetCache::find(const CacheKey&); DataResult<CacheHandle> store(const CacheKey&,const ValidatedDatasetSnapshot&,const CacheBudget&); DataResult<ManagedSourceHandle> openCompressedSource(const QString& path,const DecompressionLimits&,const std::atomic_bool&); DataResult<IndexRestore> restoreIndex(const SourceIdentity&,const IndexCachePolicy&);`. Key includes source identity/generation/watermark/prefix validation, decoding/indexer version, format/assembly/time/alignment/query/lookup versions and exactness. Index header fixes version, integer widths/byte order, checksums and validated sorted offsets. Cache only complete consistent snapshots or explicitly versioned append checkpoints, never available progress data.

Start with bounded RAM parsed-field/time sparse indexes and disk opt-in. Disk quota1GiB default, LRU/age eviction, atomic writes, concurrent reader/writer handling and clear/status/disable controls; source logs are never cache files. Do not treat size/mtime/sampled hashes as proof of unchanged bytes: unchanged-time same-size rewrites need strong prefix validation/change tokens or full reindex/no reuse. Append-resume revalidates prefix and last provisional boundary. Compressed input uses signature/frame detection, bounded streaming output and managed decompressed backing for random access; original archive/member identity is retained in SourceOrigin and exports. Defaults: max expanded2GiB, max ratio1000:1 after1MiB output, max frame window64MiB, task temp quota2GiB; all configured limits/cancellation errors are visible. Count concatenated frames according to validated library support. Do not promise tailing arbitrary compressed files. All writes must handle short writes and errors and clean partial temporaries.

- [ ] `F13_cache_rejects_stale_offsets_and_unknown_versions`: same-size same-mtime rewrite, replacement, truncate, codec change, parser/time/lookup revision, checksum corruption, out-of-range/nonmonotone offsets and unknown header version trigger a miss/full rebuild; raw results remain correct. Concurrent writers leave either valid complete file, never partially accepted data.
- [ ] `F13_append_resume_retracts_provisional_prefix`: cache ending in unterminated line resumes from that line/event's start, recomputes it once, and agrees with cold scan; an untrustworthy/network/temporary source declines reuse unless its policy is explicitly supported.
- [ ] `F13_compression_limits_and_origins_are_preserved`: extensionless zstd/lz4, supported concatenated frames, truncated/corrupt frames, excessive ratio/window/output, cancellation and injected short writes return exact error codes and remove temporary files. Decoded rows/source navigation match equivalent plain file; archive/member is retained, not replaced by a temp-path claim.
- [ ] Add `get_cache_status`, `set_cache_policy`, `clear_analysis_cache`, `get_source_compression` and bounded `open_file` compressed options. GUI/CLI/MCP agree on hits/misses/rejections/limits; folder search uses the same reader. Run current decompressor/open/index/source tests and cold/warm benchmarks including validation cost; report speed and peak memory measured, then commit.

**Acceptance:** disabling/removing caches returns correct full reads; warmed analyses never navigate stale offsets; compression errors are per-source partial outcomes where applicable. **Rollback:** disable cache reads and rebuild; disable optional input formats and clean managed backing files after active readers release them. **Primary references:** [B1](https://github.com/dm17ryk/klogg/blob/bd74c338424845a2caac03d62fdff5187e7e8f0a/src/logdata/include/sourcelocation.h)–[B3](https://github.com/dm17ryk/klogg/blob/bd74c338424845a2caac03d62fdff5187e7e8f0a/plans/log-analysis-roadmap.md), [R11](https://github.com/facebook/zstd/blob/dev/lib/zstd.h), [R12](https://github.com/lz4/lz4/blob/dev/doc/lz4_Frame_format.md).
