**Existing owners:** U04, F07, D17. **State:** planned; proposed names/files below are not implemented APIs.

**Files:** Extend src/ui/src/previewmessagetab.cpp, its header, U04 inspector adapters, F07 dataset service and existing Commander/MCP/Python/scenario registries. Test tests/ui/messageinspector_test.cpp and G03 tests/mcp/workbench_parity.py decoder cases; add docs/message-decoders.md.

Advertise only implemented operations through Commander discovery.

**Implementation steps:**
- [ ] Write GUI/service/CLI/native-MCP/Python parity fixtures for lines, discontiguous selections, completed search matches, whole sources, reconstructed lists and live feeds with explicit scope metadata.
- [ ] Add menu/toolbar/context entry points, stable object/accessibility names and lazy summary/tree/raw/hex/text panes showing contributing and explicitly excluded fragments.
- [ ] Verify selecting any contributing fragment opens the message; field selection highlights exact logical payload bytes and navigates all validated original source ranges.
- [ ] Expose typed fields to queries, Value Counts, charts, reports and assertions with explicit parent-versus-child scopes; an EHCP count never also counts its SRING container as EHCP.
- [ ] Test runtime-only drafts, revision/stale delivery rejection, missing engine, decoder edits, source append/rewrite/close and ambiguous correlations; no imported pack executes merely because a filename/log matches.
- [ ] Reuse V02 native charts. Add D17 Protocol Lab integration only when that capability is available; neither the chart task nor historical-log inspection depends on completing every transport backend.
- [ ] Before symbol edits run impact analysis and refresh relevant indexes. Register tests in existing CMake targets, tag integration tests `[ui]` or `[logdata]` as appropriate, observe failing then passing cases, run required complete checks and record evidence/limitations in PROGRESS.json. Use current build scripts from build_root.

**Acceptance:** Every advertised operation has equivalent structured data/errors and discoverability across required surfaces. GUI remains responsive, navigation validates provenance, and legacy previews still work without TShark.

**Rollback:** Disable/revert consumers and public operations before shared backend/contracts; preserve original capture data, existing JSON previews, settings and plugin-v1 compatibility.
