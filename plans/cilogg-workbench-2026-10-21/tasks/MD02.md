# MD02 — Extract envelopes and assemble bounded nested message streams

**Read first:** [decoder contract and acceptance matrix](../10-message-decoders.md), [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the owning F/E/U/D contracts.

**Integrated hard dependencies:** G01, G02, G03, F02, F04, MD03. Existing owner tasks retain their original edges; additional live/Protocol Lab/release capabilities are gated where stated below.

**Existing owners:** F02, F04, D07. **State:** planned; proposed names/files below are not implemented APIs.

**Files:** Create src/logformat/include/logrecordextractor.h, src/logformat/src/logrecordextractor.cpp, src/logformat/include/messagereassembly.h and src/logformat/src/messagereassembly.cpp; test tests/ui/messageassembly_test.cpp. Reuse F02/F04 and the MD03 result model.

**Interfaces:** ExtractedFragment -> DecoderFeedResult with consumed spans, zero/many messages, bounded pending state, need-more-data, gap/recovery evidence and transformation lineage. Protocol framing is delegated to the real Lua pack/bridge; C++ manages source/flow state and limits.

**Implementation steps:**
- [ ] Write failing cases for the declared timestamp/RX/TX envelope, literal/hex/base64/explicit escapes, UTF-16 character/file-byte mappings and exact payload ranges without implicit trimming or newline insertion.
- [ ] Test every byte split of each frame, multiple frames per fragment, split hex notifications, interleaved diagnostics and missing records. Require an explicit rule for excluding a diagnostic.
- [ ] Key assembly by source generation, endpoint/channel, direction and profile revision; expose unidentified-device ambiguity. Keep conversation correlation keys separately direction-independent.
- [ ] Implement bounded fragment routing and nested parent/child streams with expansion, depth, state and cycle limits; use the existing finite analysis lifecycle and source leases.
- [ ] Pass provisional-tail, append/rewrite, gap, EOF, cancellation and stale-navigation tests. D07 is an additional capability gate for live byte-transport adapters, not a prerequisite for historical text logs.
- [ ] Before symbol edits run impact analysis and refresh relevant indexes. Register tests in existing CMake targets, tag integration tests `[ui]` or `[logdata]` as appropriate, observe failing then passing cases, run required complete checks and record evidence/limitations in PROGRESS.json. Use current build scripts from build_root.

**Acceptance:** No invented payload bytes, flow identity or completeness; every included/excluded fragment and nested transformation retains immutable provenance.

**Rollback:** Disable/revert consumers and public operations before shared backend/contracts; preserve original capture data, existing JSON previews, settings and plugin-v1 compatibility.
