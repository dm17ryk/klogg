# F03 — Shared regex, JSON, logfmt, CSV/TSV, syslog parsers and bounded XML extension

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F01, F02. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Produce lossless typed fields with explicit parse failures across common developer log formats. **Depends on:** F01–F02; F04 before accepting quoted multiline CSV/XML records. **Current anchors:** supervised `makeRegexProcessor`; existing encoding/raw-line semantics; parser target absent. Do not require formats to be regular expressions and do not route structured values through QJsonValue doubles.

**Proposed files:** create `src/logformat/include/{eventparser,regexeventparser,jsoneventparser,logfmteventparser,delimitedeventparser,syslogeventparser,xmleventparser}.h` and matching implementations; `tests/unit/eventparsers_test.cpp`; `tests/ui/eventparserworker_test.cpp`; fixtures under `test_data/analysis/formats/`. Add formats/parser capability metadata to F02 schemas and dependency entries to `src/logformat/CMakeLists.txt`.

**Interfaces:** `class IEventParser { virtual DataResult<EventRecord> parse(const AssembledEvent&,const ParseContext&)=0; virtual ParserCapabilities capabilities() const=0; }; DataResult<std::unique_ptr<IEventParser>> makeEventParser(const LogFormatDefinition&,const ParserServices&);`. `AssembledEvent` is F04's bounded raw-decoded segments + `EventRef` (one physical segment before F04); `ParseContext` fixes schema, limits, cancellation/deadline and time policy. `ParserServices` supplies the existing capture-worker adapter, never an unrestricted executable from request JSON. `ParserCapabilities` includes streaming, multiline requirements, exact numeric/raw-span availability and supported profile version.

Choose explicit rules: JSON Lines accepts object roots by default, stable JSON Pointer field paths, bounded arrays and exact numeric lexemes; duplicates default to diagnostic Invalid, with explicit `first|last|array` profiles. Logfmt supports bare keys as present empty, quoted whitespace, escaped quote/backslash; duplicate keys have the same explicit policy. CSV/TSV fixes delimiter, quote, header mode, escape, decimal locale and null token in the profile; empty cell is String `""`, absent trailing cell is Missing, explicit configured null token is Null. Headers map to stable field IDs; duplicate/empty headers produce a deterministic validation error unless column-index mappings are supplied. Syslog supports RFC5424 PRI/version/header/structured-data + raw MSG and a distinct RFC3164 legacy profile whose missing year/zone is unresolved until F05 policy supplies it. XML is an optional registry adapter using streaming element/attribute paths, bounded depth/text/nodes, no external resource resolution; do not promise general XPath or whole-document DOM allocation.

- [ ] `F03_json_preserves_uint64_and_nested_paths`: parse UInt64 max and decimal lexemes exactly; distinguish `/a/b` from literal `a.b`; malformed JSON remains an event with `parseStatus=error`, raw reference and offset; depth 33 rejects at limit without allocating the rest.
- [ ] `F03_delimited_and_logfmt_missing_are_not_zero`: `a=0 b="" c` preserves zero/empty/present-empty and missing d; CSV `0,,NULL` differs from `0,`; doubled CSV quotes and tabs round-trip; locale never changes `1.23` to `123`. Regex optional missing capture differs from a participating empty capture; repeated matches use explicit occurrence semantics.
- [ ] `F03_syslog_and_xml_have_explicit_capabilities`: RFC5424 NILVALUE remains missing time, structured-data escaping and message BOM are preserved; RFC3164 reports unknown year/zone. XML DTD/external reference returns `unsupported_xml_entity`, depth/output limits stop parsing, and split-chunk UTF-8/XML tokens complete correctly.
- [ ] Route `parse_events` and profile preview through the existing analysis job service. Test pathological regex deadline/cancellation through the existing supervised worker, mixed malformed rows, Unicode spans and accelerated/Qt-only parity; GUI preview/CLI/MCP emit identical tagged values and errors. Run parser/config/worker suites, then commit.

**Acceptance:** parsing never removes malformed rows from the raw log or silently coerces fields.
