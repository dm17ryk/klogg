# F07 — Source-set datasets, shared service, virtual event table, and field exploration

**Read first:** [product specification](../00-product-spec.md), [execution guide](../MASTER_GUIDE.md), and the shared contracts in [02-data.md](../02-data.md). Execute only this task or its recorded independently reviewable slice.


**Integrated hard dependencies:** G01, G02, G03, F01, F02, F03. Capability-conditional dependencies described below are additional runtime gates; they do not reverse these edges.


**Purpose:** Give raw/structured/multi-source exploration and every renderer one bounded paged dataset API. **Depends on:** F01–F03; F04/F05 are optional declared profile capabilities. F16 supplies the separate optional folder capability; F07 does not depend on it and may return `unsupported_source_kind` until it is installed. **Current anchors:** widget-independent `AnalysisJobService`, `AnalysisRequest`, `freezeAnalysisRanges`, owner-thread leases/cancellation, current MainWindow/Commander routes and P05 paging. P12 table remains planned.

**Proposed files:** create `src/analysis/CMakeLists.txt`, `src/analysis/include/{analysisdatasetservice,analysissourceset,datasetcodec}.h` and matching implementations; `src/ui/include/{structuredlogmodel,structuredlogview,fieldexplorerdock}.h`, matching implementations and `src/ui/src/mainwindowdatasets.cpp`; tests `tests/ui/{analysisdatasetservice,structuredlogview}_test.cpp`, `tests/unit/datasetcodec_test.cpp`; `schemas/cilogg-query-v1.schema.json`. Modify `src/{CMakeLists.txt,logdata/CMakeLists.txt,ui/CMakeLists.txt,app/CMakeLists.txt}`, analysis service headers/implementation and single-owner Commander/app integration files serially.

**Interfaces:** implement the shared `AnalysisDatasetService` API above. Add `IAnalysisSourceReader::read(const AnalysisReadSnapshot&,const AnalysisReadCursor&,const AnalysisLimits&,const std::atomic_bool&)->AnalysisSourceBlock`, with `AnalysisReadSnapshot=std::variant<SourceSnapshot,DeferredReadSnapshot,ManagedReadSnapshot>`, `AnalysisReadCursor=std::variant<PhysicalLineCursor,ManagedByteCursor>`, and `AnalysisSourceBlock=std::variant<AnalysisRawBlock,ManagedByteBlock>`. `PhysicalLineCursor{quint64 nextLine;}` and `ManagedByteCursor{QString segmentId;quint64 nextByte;}` cannot be confused. `ManagedByteBlock{QString segmentId;RawByteRange bytesRange;QByteArray bytes;bool endOfSegment;}` does not synthesize line counts; current text processors retain their existing AnalysisRawBlock/AnalysisBatch path. F01 fixes origin contracts, F07 provides the real LogData adapter and reader factory registration, F16 provides deferred-file readers, and D01 provides managed recording readers/typed event projection. `DeferredReadSnapshot` references a manifest entry/content epoch/byte watermark; `ManagedReadSnapshot` references its registered segment/generation/watermark. No adapter fabricates a SourceSnapshot for an unopened file or byte-only frame. Real LogData readers retain owner-thread leases; source sets keep unopened entries as factories with a bounded active reader pool. No widget is captured by workers. Extend current `AnalysisJobService` internally with a source-set request and `AnalysisPipelineFactory` supplying typed-block processing, `finish(termination)` and `abort()` hooks; reuse its existing `Private::Job` registry/queues/limits. A legacy `start(AnalysisRequest,AnalysisProcessorFactory,...)` adapter preserves empty-initialization behavior and existing row schema. Pipeline finish publishes accepted-prefix aggregate state only for explicit partial limits; cancellation/stale source/I/O failure does not publish an aggregate as completed.

`StructuredLogModel::setDataset(const DatasetDescriptor&)`, `fetchMore`/paged cache, `eventRefForIndex(const QModelIndex&)` and `setVisibleFields(const QVector<QString>&)` expose the canonical schema. Keep at most ten 200-row pages in its separately accounted UI cache; no QWidget per cell/event. Raw view and table selections map through EventRef; marks/follow/context stay source linked. Field explorer shows type/unit/null/missing/invalid/parse-failure counts with sample scope and completion visible; distinct-values/sample previews are bounded query jobs, not whole-file scans on the GUI thread. Source explorer lists discovered/scanned/skipped/failed files and per-source profile, origin and clock; it can drill into one file without opening every file in tabs.
