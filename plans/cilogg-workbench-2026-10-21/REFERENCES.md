## Practical reusable components and standards

- [Apache ECharts features](https://echarts.apache.org/en/feature.html), [events/actions](https://echarts.apache.org/handbook/en/concepts/event/), [datasets](https://echarts.apache.org/handbook/en/concepts/dataset/), [transforms](https://echarts.apache.org/handbook/en/concepts/data-transform/): optional V03 renderer and V16 custom drawing. Shared C++ services retain analysis/lineage ownership.
- [Qt WebEngine 6.10 overview](https://doc.qt.io/qt-6.10/qtwebengine-overview.html), [Qt 6.10 accessibility](https://doc.qt.io/qt-6.10/qaccessiblewidget.html): versioned examples, optional deployment process, keyboard/accessibility interfaces. Recheck the actual selected Qt5/Qt6 SDK.
- [OpenSearch Dashboards](https://github.com/opensearch-project/OpenSearch-Dashboards): data-shape/configuration and interaction reference; its full server/frontend stack is a separate integration effort.
- [Logz.io Sawmill](https://github.com/logzio/sawmill), [processor documentation](https://github.com/logzio/sawmill/wiki/Processors): declarative parser/enrichment schema ideas or optional external processor. Java runtime coupling is separate from native Qt/C++ adaptation.
- [OpenTelemetry logs data model](https://opentelemetry.io/docs/specs/otel/logs/data-model/), [OTLP specification](https://opentelemetry.io/docs/specs/otlp/): typed body, source/observed timestamps, severity/resource/optional trace context and receiver mapping.
- [Docker container logs](https://docs.docker.com/reference/cli/docker/container/logs/), [Compose logs](https://docs.docker.com/reference/cli/docker/compose/logs/), [kubectl logs](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_logs/), [journalctl](https://www.freedesktop.org/software/systemd/man/latest/journalctl.html): E03–E05 adapters with real source metadata and reconnect limitations.
- [Loki HTTP API](https://grafana.com/docs/loki/latest/reference/loki-http-api/), [OpenSearch search API](https://docs.opensearch.org/latest/api-reference/search-apis/search/), [OpenObserve search API](https://openobserve.ai/docs/reference/api/search/): E07 backend query/paging/capability adapters.
- [Perfetto external trace formats](https://perfetto.dev/docs/getting-started/other-formats), [Speedscope import schema](https://github.com/jlfwong/speedscope/wiki/Importing-from-custom-sources): E08 real span/profile ingestion, V10/V13 views.
- [pytest output/JUnit notes](https://docs.pytest.org/en/stable/how-to/output.html): interoperable CI reports; reuse CILogg's existing scenario JSON/JUnit machinery.
